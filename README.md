# Campus M@N : cartes WorkAdventure (version construite)

Ce dépôt héberge, via GitHub Pages, la version **construite** (optimisée) de deux cartes :
- `bureau_virtuel.tmj` : l'intérieur du Bureau virtuel M@N ;
- `campus_man_habille.tmj` : la carte principale du campus.

Les deux cartes sont reliées : la porte du Bureau virtuel sur le campus mène à l'intérieur, et l'entrée de l'intérieur ramène sur le campus.

Les fichiers sources (scripts de construction, planches d'illustrations) ne sont pas dans ce dépôt. Ils sont conservés dans le dossier projet « Metavers M@n ».
